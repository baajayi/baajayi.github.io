Flagship

Multitenant RAG platform for faith organizations

A single production service that hosts conversational assistants for many organizations at once, each answering only from its own documents. One deployment, one codebase, strict isolation between tenants — so onboarding a new organization is configuration, not a fork.

  • Tenant isolation via per-tenant Pinecone namespaces, with opt-in shared knowledge bases
  • Three routing modes — subdomain, URL path, and an X-Tenant-ID header for API clients
  • Redis caching of query results and embeddings, with per-tenant token-bucket rate limits
  • Ingestion of PDF, DOCX, plain text and live web pages
  • Tenant-isolated S3 logging, batched, plus component-level health checks
  • Flask and gunicorn on AWS Elastic Beanstalk with autoscaling policies

Python, Flask, Pinecone, OpenAI, Redis, AWS Elastic Beanstalk, S3
